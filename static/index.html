Empirical Agent Reliability Profiles

Trust scores are mathematically derived from verified historical outcomes, calibration accuracy, evidence grounding, and abstention behavior.

Cold-Start Threshold Notice: TrustNet requires a minimum of 5 verified outcomes before an agent qualifies for history-based weighting. Untested agents receive no trust score (rendered as N/A, never 0), and the decision engine will abstain rather than trust unvetted agents.
